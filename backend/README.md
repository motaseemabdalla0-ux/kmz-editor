# KEYMAP GIS Service — Phase 1

Stateless FastAPI backend providing real Shapely/GeoPandas/GDAL/PROJ
geometry operations for KEYMAP. See:

- [`../docs/plans/KEYMAP_Phase1_Backend_Architecture_Plan.md`](../docs/plans/KEYMAP_Phase1_Backend_Architecture_Plan.md) — the approved design (API contracts, folder structure, deployment, migration plan, risks)
- [`ARCHITECTURE.md`](./ARCHITECTURE.md) — decisions made/refined during implementation
- [`SECURITY.md`](./SECURITY.md) — what's covered, what's explicitly deferred, and why

## Run it (local Docker)

```bash
cd backend
docker compose up -d
curl http://localhost:8000/v1/health
```

API docs (auto-generated by FastAPI) are at `http://localhost:8000/docs` once running.

## Run the tests

Inside the container (matches how it was verified during implementation):

```bash
docker compose exec keymap-gis python -m pytest -v
```

Or locally with a virtualenv, for faster iteration:

```bash
cd backend
python -m venv .venv
.venv/Scripts/activate      # .venv/bin/activate on macOS/Linux
pip install -r requirements.txt
pytest -v
```

27 tests, covering all seven endpoints plus the error/CORS/body-limit
guardrails — see `tests/`. The fixtures in `tests/fixtures/` are the same
reference geometries (concave polygon, polygon with a hole, adjacent vs.
overlapping pairs, a known ~100 m × 100 m square) used to verify correctness
against, ported from the earlier JS-native plan.

## Try an endpoint by hand

```bash
curl -X POST http://localhost:8000/v1/geometry/area \
  -H "Content-Type: application/json" \
  -d '{"features":[{"id":"sq","geometry":{"type":"Polygon","coordinates":[[[37.9,26.6],[37.9010048,26.6],[37.9010048,26.6008999],[37.9,26.6008999],[37.9,26.6]]]}}]}'
```

## What's NOT here yet

- No wiring into the shipped KEYMAP frontend — `../frontend/geometry-client.js`
  is the complete client, built and tested against this live service, but
  the existing toolbox buttons still use their original local math. See
  that file's header comment and the architecture plan's migration stages
  3–4 for what "wiring it in" means.
- No authentication, no PostGIS, no rate limiting — see `SECURITY.md` for
  exactly what that implies and what must land before any deployment
  beyond local Docker.
- `/geometry/union` and `/geometry/reproject` have no UI trigger yet — built
  ahead of their frontend use, per the approved design's explicit scope.
